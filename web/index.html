Build your own trading card game

This duel is one JSON file. Deckwright turns any NFT collection into a card set, its on-chain ERC-6699 stats into champions, and gives you the rules engine, a bot, two-player play and a site you can deploy in minutes.

  1. Create a game

    npx github:strodanodev/deckwright create my-tcg

    Scaffolds a playable game, its site, and an AI skill that knows the whole workflow.

  2. Bring a collection

    npx deckwright snapshot <collection address> --chain liteforge

    Reads any ERC-721 from chain: names, art and ERC-6699 stats. Then import makes the cards.

  3. Balance, play, ship

    npm run sim && npm run dev

    Bot-vs-bot balance numbers, a local site, then one static deploy. LitNode-ready rulesets for on-chain settlement.
